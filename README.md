# Scoop bucket for IWC

```powershell
scoop bucket add iwc https://github.com/Hussian007/scoop-iwc
scoop install iwc/iwc
```

This installs the official [IWC Framework CLI](https://github.com/Hussian007/iwc) release for Windows (x64, arm64). Upgrade with `scoop update iwc`. To uninstall, run `scoop uninstall iwc; scoop bucket rm iwc`.

`bucket/iwc.json` is generated and updated by each release. Please don't edit it by hand.
